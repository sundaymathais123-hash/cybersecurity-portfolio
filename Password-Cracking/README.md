# Password Cracking Simulation

## Introduction
This project demonstrates how weak passwords can be exposed through password-cracking techniques. It explores password hashes and the use of John the Ripper and Hashcat to test password strength.

## Objectives
- Understand how password cracking works.
- Examine password hashes.
- Use John the Ripper and Hashcat to test password strength.
- Identify weaknesses associated with weak passwords.
- Recommend ways to improve password security.

## Tools and Technologies
- Kali Linux
- John the Ripper
- Hashcat
- Password hash files

## Practical Activities
- Prepared password hashes for testing.
- Used John the Ripper to perform password-cracking tests.
- Used Hashcat to perform password-cracking tests.
- Examined the results and compared the tools.
- Reviewed the importance of password complexity.

## Key Findings
- Weak passwords are easier to recover through password-cracking techniques.
- Password strength affects resistance to password attacks.
- John the Ripper and Hashcat provide different approaches to password testing.
- Strong passwords and secure password storage improve security.

## Recommendations
- Use long and unique passwords.
- Avoid common words and predictable patterns.
- Use multi-factor authentication.
- Store passwords using secure password-hashing algorithms.

## Conclusion
This project demonstrated the risks associated with weak passwords and the use of John the Ripper and Hashcat for password security testing. It highlighted the importance of strong passwords
