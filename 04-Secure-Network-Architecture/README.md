# Secure Network Architecture Design, Attack Simulation and Defence Implementation

## Introduction
This project demonstrates the design and configuration of a secure network using Cisco Packet Tracer. It focuses on network segmentation, switch configuration, traffic control and testing network communication.

## Objectives
- Design a structured network topology.
- Configure switches and network devices.
- Implement VLANs for network segmentation.
- Configure trunk links between switches.
- Test network connectivity and communication.
- Examine network security through controlled testing.

## Tools and Technologies
- Cisco Packet Tracer
- Cisco routers and switches
- VLANs
- IEEE 802.1Q trunking
- IP addressing
- Command Line Interface (CLI)

## Practical Activities
- Designed a network topology using Cisco Packet Tracer.
- Configured network devices and switch interfaces.
- Configured trunk links between switches.
- Verified trunk operation using `show interfaces trunk`.
- Tested network connectivity using the `ping` command.
- Examined network traffic flow and communication between network segments.

## Key Findings
- The switch trunk interfaces Fa0/23 and Fa0/24 were operating in trunking mode.
- IEEE 802.1Q was used for trunk encapsulation.
- VLAN traffic was permitted across the configured trunk links.
- Connectivity tests helped examine communication between network devices.

## Conclusion
This project provided practical experience in network design, switch configuration, VLAN trunking and connectivity testing. It demonstrated how network segmentation and proper device configuration contribute to a more structured and manageable network infrastructure.
