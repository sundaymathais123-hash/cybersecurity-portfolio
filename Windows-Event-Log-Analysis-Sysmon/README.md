# Windows Event Log Analysis with Sysmon

## Introduction
This project demonstrates how Windows Event Logs and Sysmon can be used to monitor system activities and support security investigations.

## Tools and Technologies
- Windows 10
- Sysmon (System Monitor)
- Windows Event Viewer
- PowerShell

## Practical Activities
- Installed and configured Sysmon on Windows.
- Generated system activities to produce security events.
- Monitored process creation using Event ID 1.
- Examined process termination using Event ID 5.
- Reviewed recorded events in Windows Event Viewer.

## Key Findings
- Sysmon successfully recorded system activities.
- Event ID 1 provided information about newly created processes.
- Event ID 5 recorded process termination activities.
- These events can support investigation of suspicious system behaviour.

## Conclusion
The project demonstrated how Sysmon improves Windows activity monitoring by providing detailed event information that can help security analysts investigate potential threats.
