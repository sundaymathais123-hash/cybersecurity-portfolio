# Wireless Network Security Analysis

## Introduction
This project examines wireless network security protocols and their ability to protect wireless communication. It compares WEP, WPA, WPA2 and WPA3, identifying their security weaknesses and improvements.

## Objectives
- Understand how wireless security protocols protect network communication.
- Compare the security features of WEP, WPA, WPA2 and WPA3.
- Identify weaknesses in older wireless security protocols.
- Recommend the most secure option for modern wireless networks.

## Protocols Examined
- **WEP:** An older wireless security protocol with serious encryption weaknesses.
- **WPA:** Introduced to address weaknesses in WEP.
- **WPA2:** Improved wireless protection using stronger encryption.
- **WPA3:** Provides stronger authentication and improved protection against password attacks.

## Key Findings
- WEP is insecure and should no longer be used.
- WPA improves on WEP but is outdated.
- WPA2 provides strong protection when properly configured.
- WPA3 offers the strongest security among the four protocols.

## Recommendation
WPA3 is recommended because it provides improved authentication and stronger protection against password-based attacks. Where WPA3 is unavailable, WPA2 with AES encryption is a suitable alternative.

## Conclusion
The project demonstrated the importance of selecting secure wireless protocols. Using modern encryption and strong authentication helps protect wireless networks against unauthorized access.
